# Build plan

Order of operations bound by **dependencies, not dates**. Each step names the model that does the work: **Fable 5.1** for architecture, shared code and judgment; **Opus 5** for building modules and pages; **Sonnet 5** for mechanical passes (screenshots, Spanish fill, QA matrices). Expect repeated passes and polish; use parallel agents where steps are independent. The PM viewer (kanban / list / timeline with dependencies) is hub tool D-05 (step 13) and reads `docs/plan/plan.json`, the machine-readable projection of this file and `kanban.md` (D-037): the three must agree, and a change to one is a change to all in the same turn.

## Roadmap: own the whole operations platform (D-030)

Justin (prompt 0005): Aluzina should run on its own operations system "and not be reliant on other software at all, only their own. Maybe with some integrations but ideally we can even build those ourselves". Phases below are bound by dependencies; each names what we **build** and what we **integrate** (transport, legal validity, payment rails and AI models are commodities we buy; everything the team sees and edits we own). `docs/knowledge/tools-in-use.md` lists what each phase retires; K-05 Tools shows the live dependency map.

Parallelism: 4 and 5 can run as parallel agents per module once 3 lands; 6 runs alongside 5; 7's interface landed early inside 9a; 9b runs one agent per portal against the 9a foundation (brief: `scratchpad/foundation-brief.md` of the coordinating session, contract: `apps/hub/src/modules/README.md`), and folds into 5 where a portal is the staff / admin dashboard.

Recurring (every deploy, not a step): `npm run thumbs` regenerates the hub thumbnails from the build (D-011); knowledge entries in `docs/knowledge/` are updated the turn new information arrives (D-012).

## Definition of done (every step)

Build green and pushed to `main`; `spec.checkedAt` recorded; screenshots in `docs/screenshots/<CODE>/`; page doc; changelog entry with `model:`; kanban moved; decisions logged; prompt log when a prompt was received; `docs/reference/surfaces.md` current; the P-01..P-15 checklist in `platform-principles.md` ticked.
