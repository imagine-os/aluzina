# 0043 - fix(desk): one-row toolbar with overflow menu below 1920 px

## What changed

1. **One row where it fits.** `useToolbarFit(key)` (`apps/hub/src/desk/useToolbarFit.ts`) observes the toolbar's own width (ResizeObserver, plus `document.fonts.ready`), measures the two groups unwrapped in the layout phase (no paint in between), subtracts the page desk title's 9rem flex basis, and sets `data-desk-fold-level` 0 / 1 / 2. A key change (language, full screen, mat count, compact mode, title, placeholder) re-measures unfolded before paint. The Tilt button keeps one width for "Tilted" / "Flat" (both labels share one grid cell), so toggling it never re-measures.
2. **More menu.** `OverflowMenu` (molecule, in the component library with states closed / open / focus / disabled row): a native `<details>` whose `<summary>` is a 44 px ghost Button ("More" / "Más", named "More desk controls" / "Más controles de la mesa"), the panel a raised surface of full-width 44 px rows: Tilt (`aria-pressed`), Reset, Legend (`aria-pressed`, `aria-expanded`), Size S / M / L (`aria-pressed`, keeps the menu open), Settings. Enter / Space opens, Tab walks the rows, Escape closes and returns focus to More; focus or a pointer leaving closes it; activating a row closes it and returns focus to More.
3. **Measured at 1280 (960 px column).** Before: 975 px EN / 1 173 px ES, two rows. After (fold 1): W-05 637 px EN / 747 px ES, W-04 665 / 747 px, A-08 page desk 639 / 747 px; one row in all six. 1920: fold 0, one row, unchanged. 390 / 768: fold 0, stacked exactly as before (folding would not make one row). D-16 columns: a column that fits a folded row folds (e.g. the On its own column at 1920 EN / 3840), the rest stack as before.
4. **Actions.** No action added or changed: the 11 `desk.*` verbs call the controller (`desk.legend`, `desk.setHeight`, `desk.toggleTilt`, … checked by script with the menu folded).
5. **HOY 0.11.2 `sampleRoute`.** `HubPage` gains `sampleRoute?: string` (verbatim from HOY). Open live, "Open in hoy ↗", `clienthub.openLive` and `clienthub.openInClient` open a page at `sampleRoute ?? route`, so the nine template pages (C-03 `/app/class/sample`, C-04, C-08, C-08b, C-10, C-20, A-06 `/app/legal/terms`, M-09b, W-08 `/site/classes/hot-yoga`) open on a real record instead of the literal `:id`; the drawer's Route line keeps the template. The bundled snapshot is HOY's `public/hub-map.json` 0.11.2.
