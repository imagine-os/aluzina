# 0015 - Silver edition of the brand manual, neutral base, PDF download

Justin posted the revised manual in #aluzina-brand-kit (prompt 0014): "Here is the updated brand manual with the silver instead of gold. Make sure we can download this p. D. F from the hub." and "And please make sure that the design system is updated according to this". The gold pass (changelog 0014) had built the metal as one switchable token group for exactly this; this pass flips the switch, re-derives what the switch could not (the theme greys, the primary logo), serves the PDF, and records the manual's export defects for the brand team. The PDF was decoded the same way as the gold one (`docs/source/brand-kit/extraction-silver.md`, a diff against the gold edition): same page, same seven sections, and the changes below were verified in the vector data and in 150 dpi crops.

## A. What the silver manual changes (facts, `docs/knowledge/brand.md`)

- Primary: **Pantone 877 C**, RGB 192,192,192 = `#C0C0C0`, CMYK 0/0/0/25. Every silver fill, stroke and text span in the file is `#C0C0C0` (monogram foot, outlines now 1 pt, descriptor text, the four line patterns, the flat disc). The hex printed under the swatch still reads `#98876D`: a leftover of the gold edition, reported (D-052).
- Metallic shading: one smooth axial ramp `#FFFFFF 0% -> #E0E0E0 37% -> #999999 69% -> #4D4D4D 100%`, used on the metallic disc (0deg) and the wordmark-and-stars pattern (45deg). No bands, no second variant.
- **The primary logo is the iridescent wordmark on white** (-45deg periwinkle -> aqua -> lime), no longer metallic, with a new lockup under it: a periwinkle 1 pt slash and "INTERIORISMO / ILUMINACIÓN" in periwinkle `#C2D1F7`, DIN Round Pro Bold, wide tracking. The DESCRIPTOR section and the footer still print "UNIVERSO DE DISEÑO" in flat silver: two descriptors coexist.
- Footer band: flat black `#000000`, full bleed, iridescent wordmark, silver descriptor, thin iridescent strips at the top and bottom of the page.
- Textures: four discs (iridescent, black, metallic silver, flat silver); the four line patterns keep their geometry at 1 pt silver.
- Unchanged: the three secondaries and every iridescent gradient stop (byte-identical), the fonts, caption ink `#231F20`, the monogram and glyph geometry.

## B. Tokens (`feat(brand)`, D-050)

- `tokens.metalDefault = 'silver'`. `MetalSet` gains `gradient` (the CSS gradient exactly as decoded, 135deg) and `stops` (the ramp resampled at the five fixed SVG offsets 0 / 0.22 / 0.48 / 0.72 / 1, so the marks paint from `--metal-stop-1..5`). `metal.silver = { base #C0C0C0, highlight #FFFFFF, shade #4D4D4D, gradient white -> #E0E0E0 37% -> #999999 69% -> #4D4D4D, stops #FFFFFF #EDEDED #C8C8C8 #929292 #4D4D4D }`; `metal.gold` keeps its banded gradient as `gradient` (previous edition, preview only).
- `gen-tokens.mjs` emits `--gradient-metal`, `--gradient-metal-soft` (`softenGradient()`: each stop mixed 30% into `--color-surface`) and `--metal-stop-1..5` for the default on `:root` and for every metal inside `:root[data-metal="…"]`, instead of one generic stop list built on `var(--metal-base)`. `tokens.gradient.metal / metalSoft` are derived from the default metal, so D-10 and the CSS keep one source.
- **Neutral base**: the warm gold-tinted greys become neutral, since the primary is silver and the manual's band is black. Light: bg `#FAFAFA`, surface `#FFFFFF`, surface-raised `#F2F2F2`, text `#111111`, text-muted `#5F5F5F`, border `#E2E2E2`, hairline `#C0C0C0`, primary `#111111` / `#FFFFFF`, accent `#8A8A8A`, accent-soft `#EEEEEE`, accent-text `#3F3F3F`, focus `#4D4D4D`, metal-text `#5C5C5C`, overlay `rgb(17 17 17 / .45)`, shadow `rgb(17 17 17 / .12)`. Dark: bg `#0E0E0E`, surface `#171717`, surface-raised `#222222`, text `#F2F2F2`, text-muted `#A6A6A6`, border `#333333`, hairline `#5A5A5A`, primary `#F2F2F2` / `#0E0E0E`, accent `#C0C0C0`, accent-soft `#2A2A2A`, accent-text `#E0E0E0`, focus `#E0E0E0`, metal-text `#C0C0C0`, overlay `rgb(0 0 0 / .6)`, shadow `rgb(0 0 0 / .5)`. Status colours and the three tints unchanged.
- New raw constants `--brand-silver #C0C0C0` and `--brand-black #000000`; `--brand-gold` / `--brand-gold-highlight` stay for the gold preview.
- **Contrast adjustments** from the brief (WCAG 2.1, computed from `tokens.ts`, the numbers D-10 shows): light `accent` `#9A9A9A` measured 2.70 / 2.81 on bg / surface, below the 3:1 interface threshold, so it ships as `#8A8A8A` (3.31 / 3.45); light `warning` `#9A6B10` measured 4.49 on the new `#FAFAFA` bg (it was 4.52 on the warm `#FBFBF9`), so it ships as `#956710` (4.76 / 4.97). ## C. Marks, shells, surfaces

- **BrandMark**: `kind="wordmark"` defaults to `finish="iridescent"` (the primary logo in both themes); every other kind keeps `metal`. The metal gradient defs read `--metal-stop-1..5`, so the silver ramp (or gold, under the preview) paints the metal wordmark, the monogram stem without a tone and the glyph strokes. `kind="descriptor"` gains `variant?: 'universo' | 'interiorismo'`: `universo` (default) is "UNIVERSO DE DISEÑO" with slash and text in `--color-metal-text`; `interiorismo` is "INTERIORISMO / ILUMINACIÓN" with slash and text in `--brand-periwinkle`. Periwinkle fails contrast on white (1.5:1), so that lockup is a logo, not UI text: it always renders `role="img"` with a name (default "Aluzina: interiorismo / iluminación") and D-12 says so under house rules. The monogram foot and the glyph strokes follow `--metal-base` / `--color-metal-text` automatically: verified silver in both themes in the D-12 captures.
- **Shells**: `ShellBrand` (DesktopShell / PhoneShell), `HubHeader` and the hub hero all use the iridescent wordmark in both themes (they no longer read the theme for the finish). The hero band stays `Shimmer finish="metal"` at 0.35, now silver, with the light veil lowered from 62% to 48% so the ramp reads as metal instead of fog.
- **`.surface-ink`** (`textures.css`): `--brand-black` background, `#F2F2F2` text, 3 px iridescent strips top and bottom via pseudo-elements, `--color-metal-text` overridden to `--brand-silver` so the universo descriptor reads silver on black. Same in both themes.
- **Button** gains `download?: boolean | string` for `href` buttons (the anchor gets the `download` attribute).
- **Shimmer** fallback hexes (when the `--metal-*` vars are missing) are the silver set.
