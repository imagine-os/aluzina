## A. Foundation (`feat(design)`, D-039, D-040)

- **Palette** from the manual's four printed colours replaces the amber cues taken from aluzinaa.com: gold 875 C `#98876D` (+ highlight `#F1D7AA` decoded from the gradient shading), periwinkle 270 C `#C2D1F7`, aqua 3245 C `#82FEE7`, lime 379 C `#DDFF79`, ink `#231F20`. Semantic tokens per theme (`bg / surface / surface-raised`, `text / text-muted`, `border / hairline`, `primary / primary-text`, `accent / accent-soft / accent-text`, `focus`, `success / warning / danger / info` + `-soft`, `tint-periwinkle / aqua / lime`, `metal-text`, `overlay / shadow`). Raw brand constants `--brand-*` exist for marks and gradients only; the pastels are never text.
- **Metal is one switchable token group**: `tokens.metal = { gold, silver }`, `metalDefault: 'gold'`; `gen-tokens.mjs` emits `--metal-base / -highlight / -shade` from the default and every metal as `:root[data-metal="…"]`. Switching for real is one line + `npm run tokens`; previewing at runtime is `<html data-metal>` (`aluzina.metal`). Silver values are provisional (candidate Pantone 877 C).
- **Gradients**: `--gradient-metal` (135deg, five stops decoded from the manual: two specular streaks), `--gradient-metal-soft`, `--gradient-iridescent` (180deg periwinkle 9% -> aqua 48% -> lime 96%), `--gradient-iridescent-x`, `--gradient-iridescent-soft`.
- **Textures** (`textures.css`): four seamless SVG tiles as masks coloured by `--color-hairline` (`.texture-lattice / -chevron / -circles / -stars`, size `--texture-size` in rem so they follow `--scale`); surfaces `.surface-metal`, `.surface-iridescent(-soft)`; text `.text-metal`, `.text-iridescent` (solid fallback); `.sheen` sweep on hover / focus-within only.
- **Typography**: one family, DIN Round Pro (300 / 400 / 500 / 700 / 900) with Rubik then system-ui as fallback; `--font-display` = `--font-sans`; hierarchy by weight and tracking (`.eyebrow` uppercase 0.18em; `--tracking-caps / -wide`). Playfair Display and Roboto removed. `fonts.css` declares the five faces at `/fonts/DINRoundPro-*.woff2` with `font-display: swap`; `public/fonts/README.md` says which licensed files to drop in (never commit files without a web licence). The placeholder `.woff2` files a worker had created were deleted (they produced OTS decode warnings); the URLs stay declared on purpose so the browser falls back to Rubik until the real files land.
- **BrandMark atom** (`kind: wordmark | monogram | descriptor | glyph`, `finish: metal | iridescent | outline | flat`, `tone: periwinkle | aqua | lime`, `size sm..xl`, `label` -> `role="img"` else `aria-hidden`) over normalised paths extracted from the PDF (`src/brand/paths.ts`); standalone SVGs in `public/brand/` for docs and OG images; `index.html` gets the monogram favicon and the Rubik link.
