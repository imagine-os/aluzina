# S-01 - Studio dashboard

- route: `/#/studio`
- surface: studio
- status: built
- spec: `apps/hub/src/modules/studio/specs.ts` (`homeSpec`)
- model: Opus 5

## Purpose

Sarai's home in the studio portal (`docs/knowledge/team.md#sarai---interior-design`). It answers four questions at a glance: what is in development and with which creative direction, what she still has to check before work reaches Alejandra, what the studio owes, and which render and supplier packs are in flight. Every tile and row jumps to the page that owns the item; nothing is written here.

## Layout (top to bottom)

1. `PageHeader`: breadcrumb, h1, subtitle, `Placeholder` "New design proposal".
2. Four `StatTile`s: projects in development, checks to close, open studio tasks, packs in flight (the first, second and fourth navigate).
3. `Card` "Projects in development": `DataTable` (project, phase, creative direction, approval, due) with an Open row action.
4. `Card` "Consistency checks before the founder": `DataTable` (title, project, items ticked, status).
5. `Card` "Studio tasks": read-only `DataTable`; footer `Placeholder` "Ask operations to reschedule".
6. `Card` "Render and supplier packs in flight": `DataTable` (title, project, audience, views, due, status).

## Data

Reads `projects`, `consistencyChecks`, `tasks` (where `ownerRole = studio`), `renderPacks`. Writes nothing.

## Rules

Approval chain (`docs/knowledge/roles-and-portals.md`): the studio check precedes the founder's approval. Task status belongs to operations (`tasks.manage`), so it is read-only here.

## Logic

- In development = phase `development` or `documentation`; checks to close = status other than `passed`; packs in flight = status other than `delivered`; open tasks = status other than `done`.
- Row activation and the Open row action navigate; the tiles use `onActivate` so they are real buttons (keyboard, touch, pen, d-pad).

## Actions (P-05)

| id | label | intent | permission | params |
| --- | --- | --- | --- | --- |
| `studio.openProject` | Open project | open the project {project} | `projects.read` | `project: id` |
| `studio.openCheck` | Open consistency check | open the consistency check {check} | `projects.check` | `check: id` |
| `studio.openPack` | Open render pack | open the render pack {pack} | `renders.brief` | `pack: id` |
| `studio.newProposal` | New design proposal | start a design proposal for {project} | `design.develop` | `project: id` |
| `studio.askReschedule` | Ask operations to reschedule | ask operations to reschedule the task {task} | `design.develop` | `task: id` |
