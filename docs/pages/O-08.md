# O-08 - Administrative documents

- route: `/#/ops/documents`
- surface: ops
- status: built
- spec: `apps/hub/src/modules/ops/specs.ts` (`documentsSpec`)

## Purpose

"Administrative documents": contracts, invoices, quotes, briefs, plans and reports with their project, owner role, version and state, filterable by kind and status, and movable along the paperwork chain.

1. `PageHeader` (O-08) with a `Placeholder` "Upload document" button.

## Data

Reads `documents`, `projects`. Writes `documents.status`.

## Rules

None numbered yet.

## Logic

- Advance moves the document one step along draft -> final -> sent -> signed; a signed document offers no action.
- Kind labels are translated (`ops.documents.kind.*`), the owner column reuses the core role strings, so a document owned by the founder or the studio reads correctly in Miguel's page.

## Actions (P-05)

| id | label | intent | permission | params |
| --- | --- | --- | --- | --- |
| `ops.setDocumentStatus` | Advance status | move the document {document} to {status} | `documents.manage` | `document: id`, `status: enum:draft\|final\|sent\|signed` |
| `ops.viewDocument` | Open document | show the document {document} | `documents.manage` | `document: id` |
| `ops.openDocumentFile` | Open file | open the file of the document {document} | `documents.manage` | `document: id` |
| `ops.uploadDocument` | Upload document | upload a document for {project} | `documents.manage` | `project: id` |
