## Purpose

Where imports land. **Slack**: the mapping from Justin's sidebar (sections and channels, `docs/knowledge/taxonomy.md`) to the seeded spaces, and the checklist that is the contract for the import script (D-027); until an export exists nothing here writes. **Asana** (0020, D-062): what the CSV import already produced, counted from the generated seed files themselves. Nothing on this page writes, in either case.

## Data

Reads `spaces` (slug = channel name) and `filings` (counts), and imports the generated Asana seed files (`data/seed/asana/{hoy,portfolio}.ts`) to count them. No writes.

## Rules

None. Read-only by decision (no re-seed action, D-027).

## Logic

- The sidebar transcription is data in the page (`SLACK_SIDEBAR`, incl. the three intake channels added 2026-09-21 03:24 UTC); each channel resolves to the space with that slug under the section's area; a missing space would show "Unmapped".
- The Asana counts are computed from the imported seed arrays, never written in the strings, so the page cannot claim more than the repository holds (D-062). There is deliberately no Asana upload: the import is a repository script that emits reviewable files.
