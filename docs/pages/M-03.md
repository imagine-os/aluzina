- route: `/#/manual/services/creative-digital-consultation`

## Purpose

The remote entry point of the ladder: the client gets conceptual clarity and a professional direction before touching the space. The page is the delivery manual for service 01: what it promises, who it is for, every one of its 8 phases with the full checklist, what the client receives, and where the client goes next. Designers, operations and the founder read the same page; the working checkboxes live on the studio engagement page (`engagements.checks`).

## Layout (top to bottom)

1. `PageHeader`: the service name, the outcome as subtitle, breadcrumb Manual > Creative Digital Consultation, **Print / PDF**.
2. Header card: service code badge, ladder word "Clarity", and a definition list (central question, primary outcome, ladder word, ideal for).
3. Sticky phase index from 1280 px: one `Button` per phase, scrolling its card into view and moving focus to its title.
4. One `Card` per phase (8 of them): numbered title, the read-only checklist of its items (grouped items get a sub-heading), and the playbook's notes.
5. Delivery card: what the client receives.
6. Not included card: the scope protection list, each line marked with a cross.
7. Previous / next service links.

## Logic

- One component (`ManualServicePage`) renders all five services; this route passes `code: '01'` and its own page code, so each service keeps its own spec, nav entry, page doc and screenshot folder.
- Checklists are read-only: an empty box glyph plus the item text, which prints as a paper checklist and never pretends to be a control that does nothing (P-09).
- The phase index scrolls and focuses rather than linking to `#phase-…`, because the app runs on a HashRouter and an anchor would change the route.
- `manual.jumpToPhase` accepts a phase id (`01-1`) or just its number and does the same from the actions bus.

## Real vs mock / placeholder

## Responsive and input check (P-01, P-03)

Verified with Playwright at 360 / 390 / 768 / 1280 / 1920 / 2560 / 3840 (`spec.checkedAt`), light and dark, EN and ES: no horizontal page overflow, no console errors. Every control is a library `Button` (>= 44 px) with the global focus ring; the phase index is a `nav` of buttons, so it works with keyboard, touch, pen and (later) a d-pad; nothing is hover-only or drag-only. The index is hidden below 1280 px (the cards are already in order); 8 phase cards + delivery + not included = 10 cards in total.
