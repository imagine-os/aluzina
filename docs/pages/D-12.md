## Logic

- Colours come from `tokens.brand`, gradients from `var(--gradient-*)`, marks from `BrandMark`: no hard-coded hex in the page except the print data (RGB / CMYK strings) the manual prints.
- The metal toggle writes `<html data-metal>` and `aluzina.metal`; `modules/design/metal.ts` re-applies it on boot (the module is imported eagerly by the route registry), so the preview survives a reload. Silver is the default (D-050); gold is the previous edition.
- The download button is a static link (Vite `public/brand/`, D-051): no route, no permission, works under `base: './'`. `design.downloadManual` clicks the same link from the actions bus; the page registers it and `design.previewMetal` with `useRegisterActions` (D-036).
- The INTERIORISMO / ILUMINACIÓN lockup is periwinkle (1.5:1 on white): `BrandMark` renders it `role="img"` with a name, and the Rules card labels it a logo, never UI text (house rule).
- The light / dark plates are `data-theme="light|dark"` wrappers: `tokens.css` redeclares every `--color-*` under `[data-theme]`, so components inside render in that theme whatever the header toggle says.
- Copy hex uses `navigator.clipboard` and toasts either the value or "select it and copy by hand" when the API is blocked.
