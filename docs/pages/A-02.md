# A-02 - Approvals

- route: `/#/founder/approvals`
- surface: founder
- status: built
- spec: `apps/hub/src/modules/founder/specs.ts` (`approvalsSpec`)
- model: Opus 5

## Purpose

Final project approval, the founder's own step in the chain Sarai starts. Every project the studio has checked or handed over sits in one queue with the result of its consistency check, so Alejandra approves it, sends it back with a reason, or leaves a note without deciding.

## Layout (top to bottom)

1. `PageHeader` (A-02) with the breadcrumb back to the dashboard.
2. Card "Waiting for you": `ApprovalQueue`, one item per project, subtitle = the check summary, meta = client, phase and due date, status pill = the approval state.
3. Card "Consistency checks": `DataTable` of every studio check (title, project, items OK / total, who checked, status); a row opens the drawer.
4. Card "Already decided": dense `DataTable` of approved, client-approved and changes-requested projects.
5. `Drawer`: the check's project, author, status and notes, then the item list with an OK / open badge per line.

## Data

Reads `projects`, `consistencyChecks`, `alerts`. Writes `projects.approval`, `alerts.status`, creates `tasks`.

## Rules

Approval chain (`docs/knowledge/roles-and-portals.md`): `projects.check` (Sarai, S-08) then `projects.approve` (founder), then the client in C-xx.

## Logic

- Queue = projects whose approval is `awaiting-founder` or `in-check`, awaiting-founder first, then by due date.
- **Approve** writes `approval: 'approved'` and resolves every alert whose `entity` is `projects` and `entityId` is that project and whose status is not already resolved, so the nudge Miguel raised disappears with the decision.
- **Request changes** writes `approval: 'changes-requested'` and creates a high-priority `todo` task for the project's lead designer titled "Founder requested changes: <project>".
- **Comment** creates a normal-priority task carrying the note. There is no comments entity yet; this is the honest stand-in and is listed as a request for shared code.
- The drawer is read only: `consistencyChecks` belong to the studio.
