# G-07 - Asset library organization

- route: `/#/brand/assets`
- surface: brand
- status: built
- spec: `apps/hub/src/modules/brand/specs.ts` (`assetsSpec`)

## Purpose

"Organizing the brand's graphic assets/files" from Angélica's roster, plus the founder's rule that competition materials live in their own folders. This page shows the folder map: what exists, what is in it and what is still empty.

## Layout (top to bottom)

1. `PageHeader` with "New folder" and "Connect storage" (both `Placeholder`).
2. Four `StatTile`s: folders, files, competition folders, still empty.
3. `FilterBar`: search by path.
4. `DataTable` of folders: path, source (brand / competition), files, superseded.
5. `Card` "Not wired yet": upload, rename, move (all `Placeholder`).

## Data

Reads `brandAssets` (their `path`) and `competitions` (their `materialsFolder`). Writes nothing.

## Rules

P-01, P-03, P-05, P-09, P-13.

## Logic

- Folders are **derived, not stored**: the parent path of every brand asset plus every competition materials folder. There is no folder entity yet, so nothing here can drift from the assets.
- A competition folder with no asset counts as empty, which is the normal state until the 2027 materials exist.
- Everything that would touch files on disk is a `Placeholder`: the hub has no storage.
