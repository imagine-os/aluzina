## Logic

- Contrast is WCAG 2.1 relative luminance computed in the browser (`modules/design/contrast.ts`) against the theme's `bg` and `surface`; the verdict uses the worse of the two.
- Verdicts only appear where the design system requires the threshold: text tokens at 4.5:1 (`text`, `textMuted`, `accentText`, `metalText`, `success`, `warning`, `danger`, `info`) and interface tokens at 3:1 (`primary`, `accent`, `focus`). Backgrounds, washes, tints, `primaryText`, `overlay`, `shadow`, `border` and `hairline` show the measured ratio with a neutral "decorative, reported only" badge: a FAIL badge would otherwise read as a defect where no threshold applies.
- `overlay` and `shadow` are rgb-with-alpha, so the ratio is reported as "—".
- Search matches the token name, the CSS variable and the value; empty sections disappear and an `EmptyState` shows when nothing matches.
- The live card re-reads on resize and on a `data-theme` / `data-metal` change (MutationObserver on `<html>`).
