# W-02 - Project work

- route: `/#/<founder|ops|studio|brand>/work/:projectId` (e.g. `/#/ops/work/prj-laureles`)

- status: built

## Purpose

One project in the four Work views: its sections are the list groups, board columns and timeline swimlanes; the header names the project, its client and counts; "All work" goes back to W-01. Opened from the "Open a project…" select on W-01.
