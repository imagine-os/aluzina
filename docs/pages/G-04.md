# G-04 - Brand identity and assets

- route: `/#/brand/identity`
- surface: brand
- status: built
- spec: `apps/hub/src/modules/brand/specs.ts` (`identitySpec`)
- model: Opus 5

## Purpose

Angélica's mandate is "maintaining ALUZINA's visual consistency". This page is the identity in one place - logos, typography, palette, templates and the manual - grouped by kind, with superseded versions kept visible and marked *do not use* so nobody applies an old file.

## Screenshots

Check captures: `shots/brand/G-04-en-390.png`, `G-04-en-1280.png`. Repo set: integrator pass.

## Layout (top to bottom)

1. `PageHeader` with "Upload a version" (`Placeholder`).
2. Three `StatTile`s: current, draft, superseded.
3. `Card` "Identity manual": the guideline assets, a warning when the manual on file is superseded, "Open the manual" (`Placeholder`).
4. One `Card` per asset kind (logo, typography, palette, template, icon, photo) with a dense `DataTable`.
5. `Card` "Applying the identity": "Check a file" and "Design tokens" (both `Placeholder`).

## Data

Reads `brandAssets`; writes `brandAssets.status` (current / superseded).

## Rules

P-01, P-03, P-05, P-09, P-13. Superseded assets are never hidden: the row stays, marked.

## Logic

- Kinds render in a fixed order; empty kinds are skipped.
- The manual card compares the guideline assets: if none is `current` it says the manual on file is superseded.
- Marking superseded / current is a real write and updates the tiles live (verified).

## Actions (P-05)

| id | label | intent | permission | params |
| --- | --- | --- | --- | --- |
| `brand.supersedeAsset` | Mark asset superseded | mark the asset {asset} as superseded | `assets.manage` | asset: id |
| `brand.restoreAsset` | Mark asset current | mark the asset {asset} as current | `assets.manage` | asset: id |
| `brand.uploadAsset` | Upload a new version | upload a new version of {asset} | `assets.manage` | asset: id |
| `brand.openManual` | Open the identity manual | open the Aluzina identity manual | `brand.manage` | — |
| `brand.checkIdentity` | Check a file against the identity | check whether {file} follows the Aluzina identity | `brand.manage` | file: string |
| `brand.openTokens` | Open the design tokens | open the design tokens behind the identity | `brand.manage` | — |
