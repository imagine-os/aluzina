# P-05 - Portfolio and brochure

- route: `/#/portfolio`
- surface: public
- status: built
- spec: `apps/hub/src/modules/public/specs.ts` (`portfolioSpec`)

## Purpose

The two documents a visitor asks for before they write to the studio. Someone who lands on the services page and wants to see the work should not have to send a message to get a PDF: the portfolio and the brochure open in the page and can be downloaded in one click. `aluzinaa.com` stays the studio portfolio site (D-031); this page publishes the files and links the site for the full body of work.

## Logic

- **No session, no permission**: the route is `surface: 'public'`, `shell: 'bare'`, no `permission`; a visitor is never asked who they are.
- **Relative served paths** (`./brand/*.pdf`) so the page works under the GitHub Pages sub-path; the absolute URL for "open in a new tab" is `new URL(href, location.href)`.
- **The document on screen is `?doc=`** (portfolio by default), so `/#/portfolio?doc=brochure` is a link the studio can send.
- **The viewer is three deep**: `<object type="application/pdf">`, then an `<iframe>` for browsers without a PDF plugin, then a paragraph "Your browser cannot show PDFs here; download it instead." with the download link - which is also what a visitor sees if the file is missing from the server.
- **Read it here** selects the document, scrolls the viewer into view and focuses it, so the keyboard path matches the visual one.
- **Download** is an `<a download>` wearing the `Button` classes (the library `Button` has no `download` attribute yet; a plain `href` would open the PDF instead of saving it).
- Page count and size come from `documents.ts` and render through `toLocaleString(lang)`, so Spanish reads `2,8 MB`.

## Actions (P-05)

| id | label | intent | permission | params |
| --- | --- | --- | --- | --- |
| `public.viewDocument` | View a document | show the {doc} in the viewer | – | doc: enum:portfolio\|brochure |
| `public.downloadDocument` | Download a document | download the {doc} as a PDF | – | doc: enum:portfolio\|brochure |
| `public.openDocumentTab` | Open a document in a new tab | open the {doc} in a new tab | – | doc: enum:portfolio\|brochure |
| `public.openWebsite` | Open the studio site | open the Aluzina website aluzinaa.com | – | – |
| `public.openHub` | Open the staff hub | open the Aluzina Business OS hub | – | – |

The last two are rendered by `PublicLayout` and registered there, like every other public page.

## Components

`PageHeader`, `Card`, `Tabs`, `Button` (plus `PublicLayout`, which brings `GlobalControls` and `Placeholder`). The download control is an anchor carrying the `Button` classes; the PDF frame is plain `<object>` / `<iframe>` until a `DocumentViewer` organism exists in the library.
