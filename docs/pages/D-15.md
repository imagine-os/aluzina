# D-15 - Document

- route: `/#/docs/*` (e.g. `/#/docs/decisions.md`, `/#/docs/pages/K-03.md`, `/#/docs/plan/plan.json`)
- surface: docs
- status: built
- spec: `apps/hub/src/modules/docs/specs.ts` (`documentSpec`)
- model: Opus 5

## Purpose

One documentation file at its own address. The same viewer as [D-06](D-06.md) with that document selected, so a decision, a changelog entry, a prompt or a page doc can be linked to from a commit message, a Slack message, another page of the Hub or another document — and the link opens inside the product, not on GitHub.

## Layout (top to bottom)

Identical to D-06, plus a breadcrumb Documentation > `<file name>` in the `PageHeader`.

## Data

No entities; the document is a lazy `?raw` chunk from the `@docs` glob, or the typed plan for `plan/plan.json`.

## Rules

None.

## Logic

- The splat parameter is the path inside `docs/`, so every file in the tree has a URL; `/docs` (D-06) is the same component with `README.md` selected.
- An unknown path renders an `EmptyState` naming the path with a "Start here" button back to `README.md` — never a blank page.
- Everything else (lazy loading, caching, search, link rewriting, the plan table) is described in [D-06](D-06.md); one component serves both codes.

## Actions (P-05)

The same four as D-06: `docs.openDocument`, `docs.searchDocs`, `docs.openOnGithub`, `docs.collapseFolder`.

## Components

`PageHeader`, `SearchField`, `SpaceTree`, `Markdown`, `DataTable`, `StatusPill`, `Badge`, `Button`, `Drawer`, `EmptyState`, `Skeleton`.

## Real vs mock / placeholder

Real; no `Placeholder`.

## Responsive and input check (P-01, P-03)

Verified with Playwright at 360 / 390 / 768 / 1280 / 1920 / 2560 / 3840 (`spec.checkedAt`), light and dark, EN and ES: no horizontal page overflow, no console errors — checked on `decisions.md` (long prose + tables), `build-plan.md`, `kanban.md` and `plan/plan.json` (59-row table, which collapses to stacked cards under 768 px).

## Strings (P-13)

`docs.*`; EN and ES complete. Documents are shown as written.
