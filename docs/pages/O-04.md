# O-04 - Suppliers and follow-ups

- route: `/#/ops/suppliers`
- surface: ops
- status: built
- spec: `apps/hub/src/modules/ops/specs.ts` (`suppliersSpec`)
- model: Opus 5

## Purpose

"Liaising with and following up on suppliers": the directory with lead time, rating and state, and a drawer per supplier that gathers everything open with them right now — quotes, pending deliveries, what we still owe them — so a follow-up call can be made from one screen.

## Screenshots

`docs/screenshots/O-04/en-390.jpg`, `en-1280.jpg` — captured by the integrator.

## Layout (top to bottom)

1. `PageHeader` (O-04) with a `Placeholder` "Add supplier" button.
2. `FilterBar`: search (name, contact, city), category select, status select, count, clear.
3. `DataTable`: supplier, category, contact, city, lead time, rating, status, with pause / activate row actions.
4. `Drawer`: status and category badges, contact block, money owed, open quotes table, pending deliveries table, follow-up note (`Textarea` + `Placeholder` save) and the pause / activate button.

## Data

Reads `suppliers`, `quotes`, `deliveries`, `payments`. Writes `suppliers.status`.

## Rules

None numbered yet.

## Logic

- Pause / activate toggles `status` between `paused` and `active` (a `trial` supplier is paused like any other).
- The drawer joins by id: quotes of the supplier that are not rejected, deliveries not yet delivered, and unpaid `out` payments whose `counterparty` matches the supplier name (there is no `supplierId` on payments yet — requested).
- Money owed is the sum of `amountCop - paidCop` over those payments.

## Actions (P-05)

| id | label | intent | permission | params |
| --- | --- | --- | --- | --- |
| `ops.viewSupplier` | Open supplier | show the supplier {supplier} | `suppliers.manage` | `supplier: id` |
| `ops.setSupplierStatus` | Pause or activate supplier | set the supplier {supplier} to {status} | `suppliers.manage` | `supplier: id`, `status: enum:active\|paused` |
| `ops.logFollowUp` | Save follow-up note | log a follow-up note on {supplier} | `suppliers.manage` | `supplier: id`, `note: string` |
| `ops.addSupplier` | Add supplier | add the supplier {name} | `suppliers.manage` | `name: string` |
