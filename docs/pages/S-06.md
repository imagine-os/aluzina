# S-06 - Furniture, material and element schedules

- route: `/#/studio/schedules`
- surface: studio
- status: built
- spec: `apps/hub/src/modules/studio/specs.ts` (`schedulesSpec`)
- model: Opus 5

## Purpose

The specification lists Sarai compiles per project - furniture, materials, lighting and elements. Each schedule moves draft -> in review -> final; final schedules are what a supplier pack is built from.

## Screenshots

Not captured in this pass; working captures at 390 and 1280 in the worker scratchpad.

## Layout (top to bottom)

1. `PageHeader` with a `Placeholder` "New schedule".
2. Three `StatTile`s: items specified (sum of `itemCount`), final schedules, draft or in review.
3. `Tabs`: all / furniture / materials / lighting / elements, each with a live count.
4. `DataTable`: title, project, kind, items, due, status; row actions "Send to review" and "Mark final".
5. `Drawer`: project, kind, items, due, status, last change; `Placeholder` "Open item list".

## Data

Reads `schedules`, `projects`. Writes `schedules.status`.

## Rules

Send to review only from `draft`; Mark final only from `in-review`. Both need `schedules.write`.

## Logic

- The tab counts come from the live table, so they follow every status write.
- A schedule stores only `itemCount` today: the line items have no entity, so the item list is a `Placeholder`.

## Actions (P-05)

| id | label | intent | permission | params |
| --- | --- | --- | --- | --- |
| `studio.reviewSchedule` | Send to review | send the schedule {schedule} to review | `schedules.write` | `schedule: id` |
| `studio.finaliseSchedule` | Mark final | mark the schedule {schedule} as final | `schedules.write` | `schedule: id` |
| `studio.openSchedule` | Open schedule | open the schedule {schedule} | `schedules.write` | `schedule: id` |
| `studio.openScheduleItems` | Open item list | open the item list of the schedule {schedule} | `schedules.write` | `schedule: id` |
| `studio.newSchedule` | New schedule | create a {kind} schedule for {project} | `schedules.write` | `kind: enum:furniture\|materials\|lighting\|elements`, `project: id` |
