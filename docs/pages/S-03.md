# S-03 - References and mood boards

- route: `/#/studio/references`
- surface: studio
- status: built
- spec: `apps/hub/src/modules/studio/specs.ts` (`referencesSpec`)
- model: Opus 5

## Purpose

Sarai's design research: every reference lives on a board (one board per project chapter), carries its source and tags, and can be moved to another board as the concept settles.

## Screenshots

Not captured in this pass; working captures at 390 and 1280 in the worker scratchpad.

## Layout (top to bottom)

1. `PageHeader` with `Placeholder`s "New mood board" and "Add reference".
2. `FilterBar`: `SearchField` (title, source, note, tags), project `Select`, tag `Select`.
3. One `Card` per board (sorted by name, with its count) holding a grid of reference tiles; each tile is an activating `Card` with a thumbnail slot, title, source and tag `Badge`s.
4. `Drawer`: project, source, board, tags, note; a "Move to board" `Select`; a `Placeholder` "Upload image".

## Data

Reads `references`, `projects`. Writes `references.board`.

## Rules

None beyond the permission (`references.manage`).

## Logic

- Boards and tags are derived from the live rows, so a moved reference re-groups immediately and empty boards disappear.
- Every seeded `imageUrl` is null, so a tile shows a labelled empty thumbnail slot instead of a broken image; the upload control is a `Placeholder`.

## Actions (P-05)

| id | label | intent | permission | params |
| --- | --- | --- | --- | --- |
| `studio.openReference` | Open reference | open the reference {reference} | `references.manage` | `reference: id` |
| `studio.moveReference` | Move to board | move the reference {reference} to the board {board} | `references.manage` | `reference: id`, `board: string` |
| `studio.addReference` | Add reference | add a reference to the board {board} | `references.manage` | `board: string` |
| `studio.newBoard` | New mood board | create a mood board for {project} | `references.manage` | `project: id` |
| `studio.uploadReferenceImage` | Upload image | upload the image of the reference {reference} | `references.manage` | `reference: id` |

## Components

`PageHeader`, `FilterBar`, `SearchField`, `Select`, `Card`, `Badge`, `Drawer`, `KeyValue`, `Placeholder`, `Button`, `EmptyState`.

## Real vs mock / placeholder

Real: boards, filters, tags, the move-to-board write. `Placeholder`: add reference, new board, upload image. Thumbnails are empty slots until `imageUrl` is filled.

## Responsive and input check (P-01, P-03)

Verified at 360 / 390 / 768 / 1280 / 1920, light and dark. The tile grid is `auto-fill minmax(min(100%, 14rem), 1fr)`, so it is one tile wide on a phone; tiles are buttons (Enter / Space / tap / pen); no drag anywhere.

## Strings (P-13)

Namespace `studio.references.*` plus shared keys. EN complete, ES complete; the seeded reference content is Spanish in both languages (it is data, not UI).
