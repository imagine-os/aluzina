# S-02 - Projects and proposals

- route: `/#/studio/projects`
- surface: studio
- status: built
- spec: `apps/hub/src/modules/studio/specs.ts` (`projectsSpec`)
- model: Opus 5

## Purpose

Where Sarai develops the design proposal of each project from the creative direction Alejandra set: one card per project with phase, creative direction, approval and budget, a drawer with the project's documents, and the hand-off that sends a proposal into the consistency check.

## Screenshots

Not captured in this pass; working captures at 390 and 1280 in the worker scratchpad.

## Layout (top to bottom)

1. `PageHeader` with a `Placeholder` "New proposal".
2. `FilterBar`: `SearchField` (name, client, location, summary), phase `Select`, approval `Select`, summary, Clear.
3. Grid of project `Card`s: client and location as subtitle, `KeyValue` (phase, creative direction, approval, due), summary, "Open project" footer button.
4. `Drawer`: the same facts plus client, location, lead designer, budget and summary, a `DataTable` of the project's documents, a `Placeholder` "Request creative direction" and the "Send to consistency check" button.

## Data

Reads `projects`, `documents`. Writes `projects.approval`.

## Rules

Approval chain: only `draft` and `changes-requested` can be sent back into the studio check; everything else shows the rule as a hint instead of a button. Creative direction is the founder's to set.

## Logic

- Filters are client-side over the live table; the drawer re-reads the selected project from the table so it follows writes.
- "Send to consistency check" writes `approval = in-check` and toasts; it is rendered only with `design.develop`.

## Actions (P-05)

| id | label | intent | permission | params |
| --- | --- | --- | --- | --- |
| `studio.openProjectDetail` | Open project detail | show the detail of project {project} | `projects.read` | `project: id` |
| `studio.sendToCheck` | Send to consistency check | send {project} to the consistency check | `design.develop` | `project: id` |
| `studio.requestDirection` | Request creative direction | ask Alejandra for the creative direction of {project} | `design.develop` | `project: id` |
| `studio.newProposalDoc` | New proposal | create a proposal document for {project} | `design.develop` | `project: id` |
