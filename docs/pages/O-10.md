# O-10 - Reports

- route: `/#/ops/reports`
- surface: ops
- status: built
- spec: `apps/hub/src/modules/ops/specs.ts` (`reportsSpec`)
- model: Opus 5

## Purpose

"Formatting and laying out reports". The figures Miguel reports each month — collected, paid out, still outstanding, deliveries due, tasks closed — computed live for a chosen month, next to the report documents themselves. The layout, export and sending steps are marked as not wired yet.

## Screenshots

`docs/screenshots/O-10/en-390.jpg`, `en-1280.jpg` — captured by the integrator.

## Layout (top to bottom)

1. `PageHeader` (O-10) with a `Placeholder` "Export PDF" button.
2. `Select` "Period": the last six months.
3. Card "Figures for {month}": five `StatTile`s, the line saying what is real, and the `Placeholder` buttons "Format and lay out report" and "Send to founder".
4. Card "Report documents": `DataTable` of `documents` of kind `report`.

## Data

Reads `payments`, `deliveries`, `tasks`, `documents` (kind `report`). Writes nothing.

## Rules

None numbered yet.

## Logic

- Collected / paid out sum `paidCop` over payments of each direction whose `paidDate` falls in the period; outstanding sums `amountCop - paidCop` over unpaid payments whose `dueDate` falls in the period.
- Deliveries due counts rows whose confirmed or expected date is in the period; tasks done counts done tasks with a due date in the period.
- The period select is page state and defaults to the current month.

## Real vs mock / placeholder

Real: the period select and all five figures, recomputed from live rows. `Placeholder`: layout, export and send — there is no document template engine, PDF renderer or outbound channel yet. The page says so in a line, not only in the tooltips.
