## Purpose

Angélica works out of two shared Dropbox folders that are not projects: the **2021 campaign** (posts, ads, banners, the shoot) and the **studio asset library** (icons, QR codes, merch, templates, fonts, source files). Until now the only way to know what is in them was to scroll Dropbox. This page reads the crawl index of both folders and shows them set by set: what each set holds, how much of it the hub can actually preview, what is internal or redacted and therefore deliberately not served, and which archived project a set belongs to. It is the brand-side companion of S-12 / S-13 (the project archive), which covers folders that *are* projects.

## Layout (top to bottom)

1. `PageHeader` — breadcrumb Brand portal / Campaigns & assets.
2. **Collection switcher**: `Tabs` (Campaign 2021 | Studio assets). Under it the index `caption`, a stub banner when the index is still a placeholder, then `Shared by …`, `Shared <date>`, `Indexed <date>` and a **Open in Dropbox** link to the folder at the source.
3. **Header stats**: four `StatTile` — sets, files (hint: total indexed size), files with a preview, internal files (hint: how many are redacted).
4. **Set grid**: one `Card` per set. Card head is the set title and its folder; the body is a `Thumb` button (cover render, or the folder `FileIcon` when the set has no cover) with the file count as its badge, then the kind and visibility `Badge`s and the set size, the set note, and one ghost `Button` chip per `projectIds` entry linking to the S-13 project portal (`#/brand/archive/<projectId>`).
5. **Set view** (`?set=<id>`): a back link to all sets, the set title, its folder / kind / visibility / file count / size and the **Download set** `Placeholder`, the set note, the **contact sheet** when the index has one (plus "Open full size"), a **filter** `Input`, a `Thumb` grid of the files the hub can preview, and a row list of the files it cannot.
6. **Drawer** (one file): ext / size / dimensions / page count / state Badges, a `DocumentViewer` over the served page renders (or the served thumbnail), the file's path, its text excerpt and note, and **Open in Dropbox** / **Close**.

## Data

No entity is read for the collections themselves. The index is `docs/archive/collections/<slug>/index.json`, loaded through `apps/hub/src/domain/collections.ts` (`loadCollection`, a **lazy** `import.meta.glob` over `@docs/archive/collections/*/index.json`); renders are served from `apps/hub/public/archive/<slug>/` and addressed with `servedUrl(slug, rel)` (relative, so the GitHub Pages sub-path keeps working). `projects` is the only table read, and only to turn a `projectIds` entry into a project name for its chip; an id with no row renders as the id itself.

**Why the index is not seeded**: a collection carries one row per file, thousands of them. Seeding them would push the localStorage store over its limit and, if the glob were eager, put every file row in the main bundle. Verified after `npm run build`: the campaign index lands in its own chunk (`assets/index-jYqhq5ku.js`) and no file row appears in `assets/index-*.js`, the main bundle. The seed exposes one `assets` row per **set** (kind `file`, tag `colección`) for cross-linking elsewhere; this page deliberately does not depend on it and renders from the lazy index alone.

## Rules

P-01, P-03, P-05, P-07, P-09, P-13; D-047 (a Placeholder's action stays registered and answers "not wired yet"), D-059 (a redacted file has no preview by design — icon and sentence, never a broken image). No `GOVERNANCE_RULES` business rule applies.

## Logic

- **Collection and set live in the URL** (`?c=<slug>&set=<setId>`), so both are linkable and the browser back button walks out of a set (verified). The filter text and the open file are component state, reset whenever the collection or the set changes, so typing does not fill the history.
- **`isServed(file)`** is the single previewability test: not redacted, not `internal`, and carrying a `thumb` or `pages[]`. It splits the set view into the preview grid and the row list, and it is also what the `brand.openCollectionFile` action checks before opening the Drawer.
- **Badges are computed, never stored**: redacted from `redacted`, internal from `visibility`, RAW from the extension (`ai`, `psd`, `indd`, `dwg`, `skp`, camera raw, …) or a `raw` tag, duplicate from `duplicateOf`.
- **Folder-level redacted rows** (a folder in `path`, empty `ext`) render with the folder `FileIcon`, so a redacted folder reads as a folder rather than as an unknown file.
- **A thumbnail that fails to load falls back to the file-family icon** (the library `Thumb` does this), which is what these captures show: the stub's `thumb` path is not served yet.
- **Stub banner**: when the index carries `"stub": true` the page says the rows are examples instead of presenting them as the real folder.
- **Loading / error**: the lazy import renders "Loading the collection…" (`role="status"`) and, on failure, an `EmptyState` naming the missing file with a **Try again** button that re-runs the import.
- **Empty states**: a set with no files, and a filter that matches nothing, each get their own `EmptyState` with the query quoted back.

## Actions (P-05)

| id | label | intent | permission | params |
| --- | --- | --- | --- | --- |
| `brand.openCollection` | Open a collection | show the {collection} collection | `brand.manage` | collection: enum:campaign-2021\|studio-assets |
| `brand.openSet` | Open a set | open the set {set} | `brand.manage` | set: id |
| `brand.filterCollection` | Filter the files | filter the files by {query} | `brand.manage` | query: string |
| `brand.openCollectionFile` | Preview a file | preview the file {file} | `brand.manage` | file: string |
| `brand.closeCollectionFile` | Close the preview | close the file preview | `brand.manage` | — |
| `brand.downloadCollectionSet` | Download a set | download the set {set} as a zip | `brand.manage` | set: id |

All six register while the page is mounted (`useRegisterActions`, skipped without `brand.manage`) and were run through `window.__aluzina.actions.run`:

- `brand.openCollection {collection:'studio-assets'}` → `opened the collection "Studio assets"`
- `brand.openSet {set:'sa-icons'}` → `opened the set "Icon set" (2 files, 0 redacted)`
- `brand.filterCollection {query:'icon'}` → `filtering the files by "icon"`
- `brand.openCollectionFile {file:'01 ICONOS/sa-icon-sheet.pdf'}` → `opened the preview of "sa-icon-sheet.pdf" (thumbnail only)`, Drawer open
- `brand.closeCollectionFile` → `closed the file preview`
- `brand.downloadCollectionSet` → `not wired yet: downloading a whole set needs file storage; today the Dropbox folder is the download` (D-047: declared, behind a `Placeholder`, still answers)

`brand.openCollectionFile` accepts a path or a bare file name and, when the file belongs to another set, opens that set first. Unknown ids come back as a readable `unknown set "…"` / `unknown file "…"` instead of failing silently.

## Responsive and input check (P-01, P-03)

Verified with Playwright against `npm run preview` at **360 / 390 / 768 / 1280 / 1920 / 2560 / 3840** (`spec.checkedAt`): `scrollWidth - clientWidth === 0` at every width (no horizontal overflow), and **no interactive target under 44 px** in either dimension (measured across every visible `a` / `button` / `input` / `select` in `main`, not eyeballed). 0 console errors from the page; the only console entry is the sandbox proxy refusing the Google Fonts stylesheet, which every hub page shows.

Keyboard path, run end to end: Tab reaches the first set tile (`Open the set Social posts`, visible focus ring) → **Enter** opens the set (`?c=campaign-2021&set=c21-social-posts`, heading "Social posts") → Tab reaches a file tile (`Open c21-post-01.jpg`) → **Enter** opens the Drawer (title `c21-post-01.jpg`) → **Escape** closes it (the library Drawer's focus trap and Escape handling) → **browser Back** returns to the set grid. The `Tabs` switcher is a WAI-ARIA tablist (arrow keys, Home / End). Nothing is hover-only or drag-only: the "no preview" explanation is a `title` tooltip *on a non-interactive row*, and the same fact is also carried by the `internal` / `redacted` Badges, so it is never the only cue. Light and dark both captured.

10-foot / 4K: at 3840 the type scales through the shell's bands (h1 80 px, card titles 40 px, meta 28 px), the set grid widens to 22 rem tracks and the file grid to 14 rem tracks so tiles grow instead of multiplying, and the contact sheet is capped at `clamp(24rem, 64vh, 64rem)` so one sheet never stretches to 2000 px.
