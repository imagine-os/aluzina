## Purpose

The same spaces, posts and relations as one picture (the house pattern's graph view, cf. imagine-os/graph-gallery): pick a focus node and how far to look, filter by kind, zoom with buttons, open anything. It shows at a glance that a post sits in several spaces and what a deliverable depends on.

## Layout (top to bottom)

1. `PageHeader`.
2. Controls: focus `Select` (every space and post), depth `Select` (1 / 2 / 3 hops, everything), zoom − / value / + / Fit `Button`s, "Show archived" `Checkbox`.
3. Kind `ToggleButton`s (area, topic, role, client, deliverable, tool, project, archive, post, other entities) with the legend dot.
4. `RelationGraph` in its own scrolling container.
5. Legend: node and link counts, link styles (inside / filed in / relation), keyboard help.

## Data

Reads `spaces`, `posts`, `filings`, `relations` and the entity index tables (labels for relation targets). No writes.

## Rules

None.

## Logic

- Nodes: spaces (tone by kind, areas larger), posts, and any entity a relation points at (dashed "other" nodes with their type as a second line). Edges: `child` (tree), `filed` (dashed accent), relation kinds (arrow, `<title>` = kind).
- Kind filters apply first, then a breadth-first cut `depth` hops around the focus; when the focus itself is filtered out, its direct neighbours are kept so the page is never empty.
- Layout: the organism's own deterministic force simulation (radial start by hop distance, 300 iterations, focus pinned at the centre; no dependency, D-026). Same input, same picture.
- Zoom steps 50 % .. 300 % through buttons; Fit matches the container width once the graph has nodes; the SVG is sized in rem so it scales with the `--scale` bands at 2560+ and scrolls inside `.rgraph` (the page never scrolls horizontally).
- Keyboard: Tab reaches each node; Enter opens (space -> K-02, post -> K-03, other -> its route or a toast), Space re-centres (`?focus=`), ArrowRight / Down and ArrowLeft / Up walk the neighbours, Home returns to the focus node; the focused node's edges highlight.
