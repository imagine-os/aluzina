# A-03 - Pipeline

- route: `/#/founder/pipeline`
- surface: founder
- status: built
- spec: `apps/hub/src/modules/founder/specs.ts` (`pipelineSpec`)
- model: Opus 5

## Purpose

Every project as a card in its phase, lead to delivered. It is the founder's sales and growth view: she moves a project forward, filters by type or approval state, opens the detail of any one and marks the creative direction as set.

## Screenshots

`docs/screenshots/A-03/en-390.jpg`, `en-1280.jpg` — captured by the integrator.

## Layout (top to bottom)

1. `PageHeader` (A-03) with a "New lead" `Placeholder`.
2. `FilterBar`: `SearchField` (name, client, location), type `Select`, approval `Select`, summary "n of m projects", Clear.
3. `Kanban`: seven columns (lead, concept, development, documentation, procurement, execution, delivered), one card per project with client, budget and an approval `StatusPill`.
4. `Drawer` on card activation: client, type, phase, creative direction, approval, lead designer, budget, due date, location, summary, with the creative-direction button in the footer.

## Data

Reads `projects` (and `tasks`, `meetings` are declared for the detail view). Writes `projects.phase` and `projects.creativeDirection`.

## Rules

None numbered.

## Logic

- The Kanban moves with explicit ◀ / ▶ buttons, never drag (P-03), so keyboard, touch, pen and a future d-pad all work; each move writes `phase` by id and toasts.
- Filters combine with AND and are cleared from the FilterBar.
- "Mark creative direction as set" only appears when the project is `pending` or `revised` and the viewer has `projects.write`.
- Without `projects.write` the board is read only (no move buttons).

## Actions (P-05)

| id | label | intent | permission | params |
| --- | --- | --- | --- | --- |
| `founder.moveProject` | Move project to a phase | move the project {project} to the phase {phase} | `projects.write` | `project: id`, `phase: enum` |
| `founder.openProject` | Open project | open the project {project} | `projects.read` | `project: id` |
| `founder.setCreativeDirection` | Set the creative direction | mark the creative direction of {project} as set | `projects.write` | `project: id` |
| `founder.newLead` | New lead | add a new lead called {name} | `sales.write` | `name: string` |
