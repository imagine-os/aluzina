# docs/archive/collections/ — Dropbox collections as data

status: current · since: 2026-09-21 · source: two Dropbox folders shared by Aleja Guerra (founder) through Justin Massion in Slack #all-aluzina on 2026-09-21 (thread 1790029292.924479); downloaded as zips, unzipped locally, indexed and rendered by `scripts/archive/index-collection.py` (Fable 5.1 pipeline worker, prompt 0021, changelog 0023). The originals (12 GB) never enter the repo.

A **collection** is a shared folder that is not a project folder: the studio's own campaign and asset material. Unlike the project archive (`docs/archive/projects/`), a collection is **not** seeded file by file: `apps/hub/src/domain/collections.ts` loads `index.json` lazily (one chunk per collection, fetched when G-09 opens), and `apps/hub/src/data/seed/collections.ts` seeds **one `assets` row per set** from `sets.json` (order 76, `SEED_VERSION` 12), plus set -> project `depicts` relations and one Spanish note per collection in Brand Memory.

Files per collection:

- `<slug>/index.json` — the canonical index (`CollectionIndex`): header (title, caption, share link, who shared it and when, `indexedAt`), `totals`, `renderSettings` (the budget knobs of this run), `privacyCheck` (R7 result), `sets[]` and `files[]`. `path` is the folder-relative path with the unzip escapes decoded (`#U00d1` -> Ñ, `#U2022` -> Ñ, `#U00a7` -> ñ, `#U00f7` -> Í, `#U00b0` -> í, `#U2260` -> ¡, `#U00d7` -> ×, `#U2014` -> —; the three Mac-Roman mis-decodings were checked against DISEÑO, EFÍMERO, Medellín, ¡El diseño!). A redacted row's `path` carries the redacted name; a folder-level row's `path` is the folder and its `ext` is empty.
- `<slug>/sets.json` — the same header and `sets[]` without `files[]` (the seed input).
- `apps/hub/public/archive/<slug>/{thumbs,pages,sheets}/` — the served renders the index references (`thumb`, `pages[]`, `cover`, `contactSheet`, relative to that folder). Thumbs 512 px long edge JPEG q72 (PNG with alpha for the icon set), pages <= 4 per document (<= 3 for `.ai` over 100 MB), contact sheets 4 columns x 320 px square cells, <= 48 cells sampled evenly across the set's subfolders. Campaign pages 1200 px q72; studio pages 1000 px q68 and sheets q64 (D-069 style per-collection budget, recorded in `renderSettings`).

## Rules applied (D-059 R1..R7 ported, D-068, prompt 0021)

- **Sets** = one per meaningful folder: top-level subfolders of the campaign; in the studio folder one per space under `TODOS LOS ESPACIOS/`, one per subfolder of `IMAGENES DE PROYECTOS ALUZINA/Imagenes Reload/`, one per second-level folder of `ALUZINA/0_14_PAGINA WEB Aluzina/`, one per other `ALUZINA/*` folder; loose files of a container go to a `*-root` set. Set ids are kebab-case, unique per collection.
- **Public + render**: all of the campaign except RAW (`.cr2` / `.xmp`, index only, "RAW original") and the third-party textbook `8_Conceptos_basicos_Diseno_de_iluminacion_interior.pdf` (D-068, index only); in the studio folder the spaces, the Reload photos, `ICONOS 2024`, `LUMINARIAS`, `PRESENTACIONES`, `INSTAGRAM LU7`, the website folders, `00_ PRESENTACIONES`, `0_15_CODIGOS QR`, `01_ ARTES`, `HAPPY NEW YEAR`, `LETRERO EXTERIOR`, `0_11_ARTICULOS`, `0_METODOLOGIA`. `.ai` renders as PDF (PyMuPDF), `.gif` first frame, `.heic` through pillow-heif, `.docx` text excerpt only, `.psd` / `.dwg` / `.xlsx` index only.
- **Dedupe by md5**: 32 byte-identical duplicates in the studio folder (0 in the campaign) point at their original (`duplicateOf`) and share its render paths; one render per content.
- **Photo cap**: a set with more than 24 renderable files gets one contact sheet plus 12 thumbnails (documents first, photos sampled evenly across subfolders); the rest are index-only rows ("Shown on the set's contact sheet only"). Applied to 3 campaign sets and 7 studio sets.
- **R1 name pattern** (rut, seguridad social, planilla, cédula, contrato, comprobante, cuenta de cobro, factura, cotizaci, invoice, whatsapp image, pago, ...): name -> "<Tipo> (redactado).<ext>", no render or excerpt. Template folders (`02_MODELO COTIZACION Y CUENTA COBRO`, `06_ BRIEF PARA CLIENTES`) keep their names (internal, no render): only the real documents are redacted (`06_CUENTA DE COBRO SODIME (1).xlsx`, its duplicate, `04_FACTURA DE VENTA copy.xlsx`, and `INTERGASTRO.xlsx`, a guess: a client-named file inside `CUENTA DE COBRO`).

- **R3 content**: in price-checked sets (presentations, company docs, website, methodology, articles) a document whose text carries a currency amount or quotation wording (no. de cotización, facturar a nombre, total a pagar, forma de pago) becomes internal with no render or excerpt: `ASESORIA ALEJANDRA GUERRA.pdf`, `03_PRESENTACION_ASESORIA.ai`, `04_PRESENTACION_ASESORIA BARCELONA.ai` (consultancy fees). ## Brand-era evidence (recorded, not decided; see docs/knowledge/brand.md)

Two eras are known: portfolio "Universo de Diseño" (gold Didone wordmark) and brochure "Interiorismo · Iluminación" (light sans gradient wordmark). What these folders show:

- **Campaign 2021**: every rendered piece uses the **Didone wordmark**. The banner sources (`IMAGENES CAMPANA 2021/*.ai`, text "UNIVERSO DE DISEÑO") and the Instagram posts (Compra LU7, Medellín post) carry the metallic gold Didone wordmark with **"UNIVERSO DE DISEÑO"** and an iridescent frame. The April 2021 San Fernando print pieces (`hablador aluzina .ai`, `publicidad san fernando*.ai`, co-branded with the Origins store) already pair the gold Didone wordmark with **"INTERIORISMO · ILUMINACIÓN"**. So in 2021 the descriptor was already switching while the wordmark stayed Didone; the light sans wordmark of the brochure does not appear in 2021.
- **`01_ ARTES/Artes basicas`** is split into `IMAGEN 2018-2022` (Didone + "UNIVERSO DE DISEÑO", `aluzina style`, LU7 icons) and `IMAGEN 2023-2031` (`ALUZINA INTERIORISMO E ILUMINACION.ai`: **still the Didone wordmark**, iridescent on black, with "INTERIORISMO / ILUMINACIÓN"; matches the silver brand manual). The folder names date the descriptor change to 2023 and say the Didone wordmark continued past it.
- **`00_ PRESENTACIONES`**: the older decks (`03_ PRESENTACION ALUZINA`, `05_PRESENTACION ALUZINA Y DIRECTORA`) use the gold Didone wordmark with "UNIVERSO DE DISEÑO" on the white-iridescent slash layout; `PRESENTACIONES RELOADED 2023/ALUZINA PRESENTACION 2023 LIGHTING` and `EXPERIENCIA LUZ` slides use the iridescent Didone wordmark on black with "INTERIORISMO · ILUMINACIÓN".
- **Website 2022** (`PAGINA web 2022`, `PDF Proyectos`, `DISEÑO DE ESPACIOS`): project boards ("BREW HOUSE", "COASSIST — DETALLES DEL PROYECTO") in a thin spaced sans with photo grids; the wordmark itself is not on the boards. The same board layout appears in the campaign's `Proyectos WEB*.ai` (2021), so the 2022 website reused the 2021 boards.
- **`ICONOS 2024`**: black circular badges with thin, letter-spaced sans copy ("que hacemos ?", section icons), no wordmark; the typography matches the brochure era (light sans), the colour treatment does not (flat black, no gradient).
- Reading: the brochure's light sans **wordmark** is not in either folder; the "Interiorismo · Iluminación" **descriptor** is documented from April 2021 (print) and as the 2023+ artwork. Whether the sans wordmark is a 2024+ step or an outlier is for the founder (D-052 / kanban brand-era question).
